# GUESS THE NUMBER GAME
A simple and fun game where the user guesses a randomly generated number in your selected range. Additionaly , you can also challenge the computer in attempts !!
# Features of project 
1 Generate a random number automaticaly.<br>
2 You are able to select the range of number.<br>
3 You can also select the attempts.
